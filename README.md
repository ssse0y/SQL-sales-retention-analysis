# SQL 기반 거래 데이터 품질 점검 및 매출·리텐션 분석

## 1. 프로젝트 개요

이커머스 거래 데이터를 기반으로 데이터 품질을 점검하고,
매출 성장 현황과 고객의 재구매 패턴을 분석한 프로젝트입니다.

단순 매출 증가 여부를 확인하는 데 그치지 않고,
회원/비회원 거래 구조와 재구매율, 구매주기를 함께 분석하여
서비스의 지속적인 성장 가능성을 진단하는 것을 목표로 했습니다.

- 분석 기간: 2026.06.16 ~ 2026.06.28
- 분석 도구: BigQuery, SQL
- 주요 분석 주제
  - 데이터 품질 점검
  - 월별 매출 및 구매 지표 분석
  - 비회원 거래 분석
  - Retention 분석
  - Cohort 분석


## 2. 데이터 소개

사용 데이터는 온라인 소매 거래 데이터로,
주문번호, 상품코드, 상품명, 수량, 주문일시, 단가, 고객ID, 국가 등의 정보를 포함합니다.

| 컬럼명 | 설명 |
|---|---|
| InvoiceNo | 주문번호 |
| StockCode | 상품코드 |
| Description | 상품명 |
| Quantity | 구매수량 |
| InvoiceDate | 주문일시 |
| UnitPrice | 상품 단가 |
| CustomerID | 고객 ID |
| Country | 국가 |
| Revenue | 거래 매출 |


## 3. 분석 프로세스

1. 데이터 품질 점검
2. 매출 현황 분석
3. 비회원 거래 분석
4. Retention 분석
5. Cohort 분석
6. 인사이트 및 결론 도출


## 4. 데이터 품질 점검

분석 전 각 컬럼의 데이터 타입, 결측치, 값 분포와 이상값을 확인했습니다.

주요 점검 결과:

- `Description` 컬럼에서 결측치 확인
- `CustomerID`의 결측치가 다수 존재하여 비회원 거래로 구분
- `Quantity`에 음수 값 존재
- `UnitPrice`에 음수 값 존재
- 일부 `StockCode`에서 일반적인 상품코드와 다른 형식 확인

이를 통해 이후 분석에서 정상 거래와 비정상 거래를 구분하고,
회원/비회원 기준을 정의했습니다.


## 5. 매출 현황 분석

월별 단순 매출 비교 대신 일수 차이의 영향을 줄이기 위해
다음과 같은 월별 일평균 지표를 산출했습니다.

- 일평균 매출
- 일평균 구매 고객 수
- 일평균 구매 건수

### 주요 인사이트

- 12월 기준 전년 대비 일평균 매출 약 94.5% 증가
- 일평균 구매 고객 수 약 100% 증가
- 일평균 거래 건수 약 81% 증가
- 9월 이후 주요 지표가 지속적으로 상승하며 연말에 높은 성장세 확인

다만 연말 선물 수요 등 계절적 요인의 영향 가능성이 있어,
단순 성장률만으로 지속 성장을 판단하기는 어렵다고 보았습니다.


## 6. 비회원 거래 분석

`CustomerID IS NULL`인 거래를 비회원 거래로 정의하고
월별 거래 구조를 분석했습니다.

분석 지표:

- 월별 비회원 거래 비중
- 월별 비회원 매출 비중
- 월별 비회원 주문건당 평균 매출

### 주요 인사이트

- 비회원 거래 비중은 전반적으로 감소하는 추세
- 그러나 특정 시점에 비회원 매출 비중이 크게 상승
- 일부 비회원 거래에서 주문건당 매출이 크게 증가

따라서 비회원 거래 중 잠재적 고가치 고객이 존재할 가능성이 있으며,
회원가입 유도 등을 통해 고객 단위 행동 데이터를 확보할 필요가 있다고 판단했습니다.


## 7. Retention 분석

고객의 첫 구매 월을 기준으로 이후 재구매 여부를 추적하여
월별 재구매율을 분석했습니다.

### 주요 인사이트

- 12월 유입 고객은 기존 고객이 섞여 있어 상대적으로 높은 재구매율을 보임
- 이후 신규 유입 고객의 재구매율은 상대적으로 낮게 나타남
- 특정 시즌에 유입된 고객은 이후 구매가 감소하는 패턴 확인

이를 통해 신규 고객 확보뿐 아니라
첫 구매 이후 재구매를 유도하는 전략이 중요하다고 판단했습니다.


## 8. Cohort 분석

첫 구매 월을 기준으로 Cohort를 구성하고
구매 후 경과 기간에 따른 Retention 변화를 분석했습니다.

Cohort별 재구매율을 비교하여
신규 고객이 어느 시점에서 가장 많이 이탈하는지 확인했습니다.


## 9. 결론

분석 결과 매출과 고객 수는 성장하고 있었지만,
단순 매출 증가만으로 지속 가능한 성장을 판단하기에는 한계가 있었습니다.

특히

- 신규 고객의 낮은 재구매율
- 특정 시즌에 집중된 매출
- 비회원 거래로 인한 고객 행동 추적의 한계

가 주요 과제로 확인되었습니다.

따라서 향후에는

1. 첫 구매 고객 대상 재구매 프로모션
2. 시즌별 고객 특성을 반영한 마케팅
3. 비회원 고객의 회원 전환 유도

등을 통해 고객 기반의 지속적인 성장 구조를 구축할 필요가 있습니다.
